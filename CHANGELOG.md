# Changelog

## 0.1.0

Initial public preview of the MyEscapePlan TypeScript and Python SDKs.

- TypeScript package `@myescapeplan/sdk`.
- Python package `myescapeplan`.
- Discovery, verified-search polling, results, usage, and API-key
  authentication against the production Business API.
- Progressive streaming remains in the canonical OpenAPI contract but is
  intentionally excluded from the generated v0.1 SDKs.

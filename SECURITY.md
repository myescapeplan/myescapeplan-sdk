# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to
**engineering@myescapeplan.app**. Do not open a public GitHub issue for a
vulnerability or include exploitable details in a public discussion.

## Scope

This policy covers the SDK source, generated package artifacts, release
automation, and documentation in this repository. It does not replace the
MyEscapePlan Business API's own security or support process.
